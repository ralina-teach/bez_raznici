# База данных магазина обуви

Схема: `bez_raznici`. MySQL, InnoDB, кодировка базы и SQL - UTF-8.

## Восстановление

1. Откройте `create_v1.sql` в MySQL Workbench и выполните в отдельной пустой схеме.
2. Выполните `data.sql` - дамп только данных, полученный через mysqldump.
3. Проверьте количество записей. Повторно импортировать CSV не нужно.

`create_v1.sql` сгенерирован из `bez_raznici.mwb` через Forward Engineering.
Файлы рассчитаны на пустые таблицы. Они не очищают существующие данные.

## SQL для приложения

В `queries.sql` собраны 11 запросов для входа, каталога, поиска, фильтрации,
сортировки и работы с товарами. `?` - параметры. Это заготовки отдельных команд
для C#, файл не нужно выполнять целиком как скрипт заполнения базы.
В Workbench запросы с параметрами проверены через PREPARE и EXECUTE.

Права ролей и проверки ввода будут выполняться в приложении.
Внешние ключи дополнительно запрещают удалить товар, включённый в заказ.

## Актуальные данные

| Таблица | Строк |
|---|---:|
| categories | 2 |
| manufacturers | 6 |
| suppliers | 2 |
| roles | 3 |
| users | 10 |
| pvz | 36 |
| orderstatus | 2 |
| products | 10 |
| orders | 10 |
| prodorders | 20 |

Всего 101 запись, включая 10 товаров. После восстановления в другой пустой
схеме все значения записей совпали с исходной базой.

CSV сохранены в изменённом формате: разделитель `;`, русскоязычные файлы -
Windows-1251, числовые файлы с датами читаются как UTF-8. Даты в CSV имеют
вид ДД.ММ.ГГГГ; при загрузке в DATETIME они преобразованы в формат MySQL.
Пустые строки в orderstatus.csv не являются записями и при загрузке пропущены.
В prodorders.csv исправлены две ссылки: товар 11 заменён на 1, товар 12 - на 2.
Остальные пользовательские изменения CSV сохранены.

Проверены вход и неверный пароль, 10 строк каталога, поиск и фильтр,
оба направления сортировки и их совместная работа, справочники формы,
добавление, чтение по id, изменение и удаление новой позиции.
Удаление купленного товара отклонено MySQL с ошибкой 1451.
Тесты не оставили новых или изменённых записей.

Модель и ER-диаграмма остались актуальными: структура таблиц и девять связей не менялись.
