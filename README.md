Магазин обуви - Учебный проект по разработке информационной системы для автоматизации работы магазина обуви.
Команда: Минсабирова Ралина, Шамсутдинов Айнур
Тех. стек: ЯП - C#
          Платформа / Фреймворк - .NET
          База данных - MySQL Workbench
          Система контроля версий - GitHub

Структура репозитория:
docs/ - документация проекта
db/ - скрипты создания и наполнения базы данных, схемы
src/ - исходный код приложения
